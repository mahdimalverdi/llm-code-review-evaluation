# Abstract

Large language models can produce fluent code review comments that are unsupported, irrelevant, or too costly to verify. Existing evaluations increasingly move beyond lexical similarity, yet comment quality, workflow outcomes, and evaluator validity are often studied separately. This targeted structured literature review with an auditable supplementary search amendment synthesizes 121 full-text studies of automated code review and related evaluation methods using evidence tiers and thematic analysis. The review yields four main findings. Problematic feedback can originate in the generated comment, its context, the review workflow, or the evaluation process. Common quality dimensions remain non-equivalent: relevance and acceptance do not establish correctness or usefulness. Mitigation can reduce one risk while worsening another, but preservation, coverage, and cost are reported inconsistently. Finally, context and LLM-based evaluators can introduce noise, bias, and manipulation risk. We use these findings to propose a failure taxonomy and a framework that connects assessment to decisions about displaying, revising, withholding, or escalating feedback. The original search history of the 71-study historical baseline was not preserved, so claims about the literature are bounded to the assembled corpus and the proposed instruments are not treated as empirically validated.
